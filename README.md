# Choros website — redesign concept

Static HTML/CSS concept for the restructured choros.io. Not live on choros.io.

- **Preview:** GitHub Pages (see the repo's About link). Every page is `noindex`.
- **Run locally:** `python3 -m http.server 4321` from this folder, then open http://localhost:4321

Structure: `index.html` (home), `ai-implementation/`, `software-development/`, `marketing/` (+ 3 sector pages), `solutions/`, `work/` (3 case studies), `about/`, `insights/`, `contact/`. Styles in `assets/css/main.css`, script in `assets/js/main.js`.
